# metformina-dose-dumping

Repositorio de planeación, documentación, registros, análisis y control de calidad para el proyecto:

**“Validación cruzada y evaluación de perfiles de disolución de metformina de liberación modificada en refresco para el estudio de dose dumping.”**

## Enfoque actual del proyecto
- Técnica analítica principal: **Cuantificación UV-VIS**.
- Matriz refresco inicial: **Coca-Cola**.
- `% de refresco (v/v)`: **obligatorio en registros y editable** (variable según avance).
- Longitud de onda (λ): **POR DEFINIR** (se registra explícitamente en planeación y ejecución).
- Endpoints finales: **f2**, **%TMD** y otros análisis definidos en protocolo.

## Cómo usar este repositorio
- Empieza en `PROMPT_MAESTRO.md` para el estándar de trabajo con el asistente.
- Planeación y control de cambios: `01_Planificacion/`.
- Documentación viva de validación UV-VIS: `01_Planificacion/Documentos_validacion_metodo/`.
- Métodos y alineación normativa (USP/NOM/FEUM): `02_Metodos_y_normatividad/`.
- Formatos de registro y diccionario de datos: `03_Registros_y_datos/`.
- Guías de análisis (Excel/Minitab) e interpretación: `04_Analisis_bioestadistico/`.
- Desviaciones y CAPA: `05_Calidad_desviaciones_CAPA/`.
