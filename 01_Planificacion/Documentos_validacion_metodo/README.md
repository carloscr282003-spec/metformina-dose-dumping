# Documentos de validación de método (UV-VIS)

Carpeta viva para la documentación requerida durante la validación del método analítico.

## Estructura
- `00_Planeacion/`: protocolo, matriz de criterios, checklist previo.
- `01_Ejecucion/`: bitácoras y formatos de registro de datos.
- `02_Conclusiones/`: reporte final de validación y conclusiones.

## Nota de alcance
- Técnica principal: UV-VIS.
- Refresco inicial: Coca-Cola.
- `% de refresco v/v`: obligatorio y editable en registros.
- λ: mantener como **POR DEFINIR** hasta su definición formal.
