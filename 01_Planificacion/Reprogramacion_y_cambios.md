# Reprogramación y cambios (log de cambios)

> Registro maestro de cambios del proyecto (cronograma, método, endpoints, criterios, herramientas, etc.).

## Cómo usar
- Un registro por cambio relevante.
- Mantén enlaces a evidencia (registros, datasets, análisis, desviaciones).
- Si el cambio afecta comparabilidad, documenta evaluación de impacto.
